# MasterVideo

**MasterVideo** là phần mềm Windows giúp làm video tài liệu YouTube không lộ mặt (faceless) gần như tự động:
kịch bản → giọng đọc AI → ảnh / clip AI / cảnh 3D → dựng video có phụ đề → cắt Shorts → gói đăng YouTube.

*MasterVideo is a Windows app that builds faceless YouTube documentary videos almost automatically:
script → AI voice-over → AI images / clips / 3D scenes → edited video with captions → Shorts → YouTube upload pack.*

## Tải về / Download

Vào mục **[Releases](../../releases/latest)** và tải file `MasterVideo_Setup_V….exe` mới nhất.
*Go to **[Releases](../../releases/latest)** and download the latest `MasterVideo_Setup_V….exe`.*

- **Dùng thử miễn phí 7 ngày**, không cần key. Mở mọi tính năng trừ *Tìm kiếm & phân tích ngách*.
  *Free 7-day trial, no key needed — everything except niche research.*
- Phần mềm **tự báo và tự cập nhật** khi có bản mới (nút CẬP NHẬT màu đỏ trên bảng điều khiển).
  *The app notifies you and updates itself when a new version is out.*
- Windows có thể hiện cảnh báo SmartScreen vì bộ cài chưa ký số: bấm **More info → Run anyway**.
  *Windows SmartScreen may warn because the installer is not code-signed yet: click **More info → Run anyway**.*

## Mua key / Buy a licence

Sau 7 ngày, cần key gói ĐẦY ĐỦ. Trong bảng điều khiển → mục **Bản quyền** → bấm **Sao chép mã máy**, rồi gửi mã máy tới
**thanglducraina@icloud.com** để mua key.

*After 7 days a full licence key is required. In the control panel → **Licence** → **Copy machine code**, then email it to
**thanglducraina@icloud.com** to buy a key.*
